## Publicar en GitHub Pages

1. Descomprime el ZIP.
2. En el repositorio `Genes-Creativos`, elige **Add file → Upload files**.
3. Sube **el contenido** de esta carpeta a la raíz y confirma los cambios.
4. En **Settings → Pages**, usa `Deploy from a branch`, rama `main`, carpeta `/(root)`.
5. Abre `https://dariovera07.github.io/Genes-Creativos/`.

Las carpetas `moda`, `branding`, `digital`, `quienes-somos` y `mision-vision` solo redirigen enlaces antiguos a la sección correcta de la landing.
